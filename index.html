Документы дома

Заполните поля — получите готовый документ официально-делового стиля. Пустые поля подставляются как «___», чтобы дозаполнить вручную.

📄

Выберите документ слева

Доступно 13 шаблонов: уведомления, протокол, бюллетени, отчёты, акты, претензии, договор.

Предпросмотр

Реквизиты дома

Заполняется один раз. Эти данные автоматически подставляются во все документы — шапка, подписи, банковские реквизиты.

Кворум и подсчёт голосов

Арифметическая проверка собрания: доли голосов считаются по площади помещений. Пороги вынесены в поля — подставьте значения из актуальной редакции закона и устава.

Исходные данные

Голоса по вопросам

Одна строка — один вопрос, в формате: Формулировка | за | против | воздержался (в м²).

Результат

Введите данные слева.

⚠️ Конкретные значения кворума и порогов принятия решений устанавливаются законодательством и уставом. Перед применением сверьте их с актуальной редакцией на adilet.zan.kz.

Правовая база

Ориентиры для проверки. Ссылки со значком «проверено» ведут на карточку документа в ИПС «Әділет»; остальные открывают поиск по сайту.

⚠️ Законодательство и типовые формы меняются. Реквизиты актов ниже приведены как ориентир — перед использованием обязательно откройте актуальную редакцию на adilet.zan.kz. Ассистент не заменяет юриста в спорных и судебных ситуациях.

Инструкция для Claude Project

Готовый текст системной роли. Вставьте его в Project instructions — и ассистент перестанет требовать объяснения контекста в каждом чате.

  1. claude.ai/projects → «+ New Project» → название, например «Управляющий МЖД».
  2. Настройки проекта → раздел Instructions.
  3. Вставьте текст ниже целиком и сохраните.
  4. В Project knowledge загрузите материалы дома: устав, смету, реквизиты, список собственников.
  5. Все новые чаты внутри проекта используют инструкцию и файлы автоматически.

Project instructions доступны на платных тарифах (Pro и выше).
